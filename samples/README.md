# Sample corpus

Three synthetic documents that imitate the Markdown a PDF layout parser
(MinerU / Marker / PP-StructureV2) emits for a visually rich document: pipe
tables that run for dozens of rows, figure references with separate captions,
display formulas in fenced blocks, and a deep heading hierarchy.

They are **synthetic** -- written for this repository, not extracted from any
real report -- so the corpus can be redistributed freely and the benchmark in
`benchmarks/run_benchmark.py` is reproducible by anyone who clones the repo.
Numbers in the tables are illustrative and are not investment research.
