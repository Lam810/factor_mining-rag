# 价值因子在A股市场的有效性再检验

## 1 研究背景

价值因子自Fama和French提出以来长期被视为横截面收益的核心解释变量之一。然而在A股市场，
其表现受制于行业结构、壳价值以及监管周期，稳定性显著弱于成熟市场。本报告在统一的数据口径
下重新检验账面市值比、市盈率倒数与自由现金流收益率三类价值代理变量的有效性。

## 3 方法

### 3.1 因子合成

三类代理变量先做行业内去极值与标准化，再按等权合成为综合价值因子：

```
V_{i,t} = (z(BP_{i,t}) + z(EP_{i,t}) + z(FCFP_{i,t})) / 3
```

### 3.2 组合构建

每月末按综合价值因子分十组，等权持有，次月首个交易日调仓。停牌股票按前一交易日权重顺延。

## 5 结论

价值因子在A股整体有效，但收益高度集中于金融与地产等重资产行业；在电子、计算机等
成长属性较强的行业中几乎失效。这提示在实盘中应当采用行业内中性化而非全市场排序。
